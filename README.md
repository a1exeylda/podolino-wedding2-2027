# Свадебное приглашение — Подолино

Статический сайт-приглашение для свадьбы 26–27 февраля 2027 года.

## Содержимое

- `index.html` — страница сайта и стили
- `assets/` — иллюстрации, фотографии, марки, зимние сцены и музыкальный файл

## Загрузка в GitHub

1. Создайте пустой репозиторий на GitHub.
2. Загрузите в корень репозитория `index.html`, папку `assets/` и этот `README.md`.
3. Для публикации через GitHub Pages откройте **Settings → Pages**, выберите публикацию из ветки `main` и папку `/ (root)`, затем нажмите **Save**.

Сайт не требует сборки или установки зависимостей. Музыка запускается после нажатия гостем кнопки на заставке.
